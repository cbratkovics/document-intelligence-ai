# Northwind Outfitters onboarding checklist (PEO-2024-05)

Sample data for evaluation. Northwind Outfitters is a fictional company.

## Before day one

- Hiring manager submits the equipment request at least 7 days before the start date.
- IT creates accounts and enrols the laptop in device management.

## First week

- New hire completes security awareness training within 5 working days.
- New hire reads the remote work policy HR-2023-11 and the expense policy FIN-2024-02.
- Manager schedules a 30-day check-in.

## First month

- New hire attends the monthly office day in Chicago.
- Access to production systems is granted only after the security training is complete.
